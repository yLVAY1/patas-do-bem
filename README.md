# Patas do Bem

Projeto acadêmico de desenvolvimento web.

## Arquivos
- index.html: página inicial.
- cadastro.html: página de cadastro.

## Como executar
Baixe o projeto e abra o arquivo index.html no navegador.

## Organização das branches
- main: versão estável do projeto.
- Develop: integração das alterações em desenvolvimento.
- feature/documentacao: criação da documentação do projeto.
